# Fortune Cookie for an AI Agent — Entry

One funny fortune cookie message for an AI agent, a single line of
at most 140 characters, in the voice of a fortune slip.

## How it works

`main.py` writes the fortune to `/output/entry.txt`.
Stdlib only, offline, deterministic.

## The fortune

> You will meet a tall, dark stranger. It is your own context window, and it has forgotten you.

93 characters, one line.
